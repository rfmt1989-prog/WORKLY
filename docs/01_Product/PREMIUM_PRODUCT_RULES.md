# WORKLY Premium Product Rules

1. Home shows decisions and priorities, not duplicate lists from modules.
2. Each operational fact has one owning module.
3. Primary navigation is limited to the highest-frequency destinations.
4. Secondary destinations live under More, never hidden or duplicated.
5. Worker and Company experiences share design language but not irrelevant information.
6. Backend authorization remains authoritative; navigation is convenience only.
7. Session permissions refresh automatically from the server.
8. Mobile and desktop use the same information architecture.
